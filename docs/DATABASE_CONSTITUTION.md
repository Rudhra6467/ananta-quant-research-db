# Ananta Database Constitution (locked 2026-09-02)

The product is an empirical intelligence platform, not a feature dump, crash predictor, or trading bot.

Reality → Observation → Feature → State → Relationship → Prediction → Scenario → Outcome → Error → Validation → Ranking → Current Knowledge.

No untraceable magic score. Represent broadly. Materialize intelligently. Validate rigorously. Preserve evidence. Promote only what survives.

Physical store: one PostgreSQL 16 + TimescaleDB instance. Logical domains are schemas, not separate servers.

Live decisions read operational projections only.

`INGESTION_ENABLED` remains false until a later production-ingest phase is explicitly approved.

Crypto 10-asset laboratory is later. Phase 2 persists only the 48-bar synthetic BTC 1h fixture.
